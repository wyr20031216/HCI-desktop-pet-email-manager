## v2.1（本次）核心变化：桌宠交互升级为两级

1. **单击桌宠 → 功能宫格（L0）**：2×3 磁格列出五大功能 + 完整面板入口，磁贴带实时角标（待确认数 / 重点邮件数 / 临期数）：
   - **今日面板**：横幅三态 + 四类统计 + 临期卡 + 待确认卡 + 等待条件条
   - **邮件重点**：AI 标出的重点邮件列表，每封附"为什么重要"依据标签（截止时间/行动项/待确认），点击跳转原文与证据
   - **当前任务**：按 待确认 / 待处理·临期 / 待处理 / 等待条件 分组，支持就地确认、完成、稍后提醒
   - **免打扰**：详情页含开关、自动时段、临期穿透提醒（FR-06）
   - **系统设置**：免打扰 / 减少动画 / 桌宠置顶快开关 + 更多设置入口
2. **导航与返回**：详情页头部出现 ‹ 返回；Esc 返回宫格、再按关闭；Alt+P 随时开关；底部主按钮随当前页跳转任务窗格对应视图。
3. **界面优化**：磁贴 hover/按压反馈；**紧凑模式**（可用高度 <500px 时宫格自动切换 3×2 横排并隐藏描述，矮窗口 600px 高实测 6 磁贴全部可见无滚动）；`.app` 最小高度 760→560 修复矮窗口定位失真；弹框打开时对越界桌宠做防御性钳位。
4. **修复**：弹框内点击"确认"后内容重渲染导致事件源脱离 DOM、被误判为外部点击而关闭弹框的问题（外部点击守卫增加 `isConnected` 判断）；任务确认后今日面板/任务详情卡片状态同步（assignDone 状态）。

## v2.0 相对 v1 的核心变化

1. **点击桌宠 → 快捷弹框（本次核心需求）**：单击桌宠在其次上方弹出非模态弹框（380px）：临期横幅（红）/免打扰横幅（灰）/空闲横幅（绿）三态、四类任务统计、临期卡（查看/稍后提醒/完成）、待确认卡（确认/查看依据）、等待条件条、底部「打开完整面板 / 免打扰 / 设置」。Esc / 点击外部 / 再次单击关闭；Alt+P 快捷开关。
2. **桌宠五业务状态（FR-07）**：待机 ✦ / 待确认（琥珀角标 n）/ 临期（红角标 n + 脉动，开启"减少动画"后关闭）/ 成功（绿 ✓ 瞬态 2.2s）/ 免打扰（灰 ☾）。状态用「图标+数字+文字」双通道表达，不依赖颜色。优先级：免打扰 > 临期 > 待确认 > 待机。
3. **拖拽与位置记忆**：桌宠可拖动（限制在 Outlook 窗口内），位置存 localStorage，刷新恢复。
4. **右键菜单**：打开快捷面板 / 打开完整面板 / 免打扰 / 稍后提醒 / 设置 / 隐藏到托盘。
5. **托盘**：隐藏后窗口右下角出现「⛶ MailPet 已在托盘 · 点击恢复」气泡，单击恢复原位。
6. **弹框智能定位**：默认桌宠右上方 16px；上方空间不足翻转到下方；两侧都不足时压缩弹框高度并内部滚动，任何情况下不遮挡桌宠、不溢出窗口。
7. **Outlook 加载项形态**：工具栏新增「✦ MailPet」加载项命令（开关任务窗格）；侧栏标注"Outlook 加载项 · 任务窗格"；邮箱连接由 IMAP 配置改为 **Outlook 宿主授权（Graph · Mail.Read 只读）**——应用不保存密码、不改服务器邮件状态（FR-01 只读要求）。
8. **设置内新增"桌宠状态预览"演示工具**：一键切换五种状态供评审演示。

## 实现提示（真实加载项）

Office.js 加载项不支持跨窗格悬浮层：桌宠与弹框需运行于任务窗格（或加载项页面）内，弹框可用窗格内浮层实现；本原型的尺寸、状态机与流程可直接映射。数据面遵循 FR-11：本地存储、只读权限、日志脱敏。
